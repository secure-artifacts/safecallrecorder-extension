SafeCallRecorder

录音默认保存在本机；启用 Google 云端上传后，MP3 可同步到 Google Drive。

第一次使用？按照 3 步开始录音

  1. 选择声音设备
  2. 确认音浪有变化
  3. 点击开始录音

最安全。停止后马上取得录音，MP3完成后再自动下载。

标准适合普通通话：短暂停顿不会立刻显示“没有声音”。

「标签页」：在浏览器中打开 mp3/mp4 并开始播放时自动录音。「插件内」：下方播放列表按顺序全部播完后再自动开始，播放过程中不会提前录音。

请确保所选设备能收到播放声音（例如 VoiceMeeter Out B1）。

隐私：录音只保存在本机浏览器存储中，不会上传。

    Google 云端上传

    首次使用？需要先用 Google 账号在 Google Cloud 免费创建 OAuth 客户端（约 5–10 分钟，只需配置一次）。以下按钮名称均按 Google 中文界面书写，请对照你屏幕上看到的文字点击。

    创建 OAuth 客户端时会用到（请先记住）：
    扩展 ID：—
    Web 应用重定向 URI：—
    扩展 ID 与 chrome://extensions 页面显示的一致；重定向 URI 仅在选择「Web 应用」类型时需要，请完整复制（含末尾 /）。

    在 Google Cloud 创建客户端后，把生成的客户端 ID 粘贴到上方输入框。

    步骤 1：创建 Google Cloud 项目（没有项目就无法继续）

    推荐：直接打开新建项目页面（不用自己找按钮）

    1. 先登录 Google 账号，然后点击：→ 打开「新建项目」页面
    2. 在 项目名称 输入框填：SafeCallRecorder（或任意名称）
    3. 位置 保持默认「无组织」即可，不用改
    4. 点页面上的 创建 按钮（通常在输入框下方或右下角）
    5. 等待约 10–30 秒，浏览器右上角可能弹出「项目已创建」通知

    若你想手动找「新建项目」按钮，按这个路径：

    1. 打开 Google Cloud 控制台首页
    2. 看页面最顶上一行：左边是 ☰ 菜单，旁边是 Google Cloud
    3. Google Cloud 右边是 项目下拉框（可能显示项目名，或「选择项目」）→ 点它
    4. 弹出「选择项目」窗口 → 看窗口右上角的 新建项目 按钮（有时在窗口顶部「新建项目」标签页）→ 点它
    5. 填写项目名称 → 点 创建

    找不到「新建项目」？ ① 确认已用个人 Google 账号登录（公司账号可能被管理员禁止建项目）； ② 直接用上方「打开新建项目页面」链接； ③ 若列表里已有项目，也可不新建，在「选择项目」窗口里点选已有项目后继续步骤 2。

    创建后必做：再看一次页面顶部项目下拉框，确认显示的是你刚建的项目名（有时不会自动切换，需手动点选）。

    步骤 2：配置 OAuth 同意屏幕（左侧菜单「Google Auth Platform」）

    你会看到的左侧菜单（中文）：概览 · 品牌塑造 · 目标对象 · 客户端 · 数据访问 · 验证中心 · 设置

    1. 点击：→ 打开 OAuth 同意屏幕
    2. 确认页面顶部当前项目是你刚创建的项目（不对就先回步骤 1 切换）
    3. 首次进入时，在 概览 页点 开始 或 配置同意屏幕
    4. 点左侧 目标对象（你截图里那一项）：
      • 个人 Gmail：选 外部（内部 是灰色不可点 → 正常，需要公司 Workspace 账号）
      • 选好后点 创建 或 保存

    5. 只想自己用、不想给别人用？ ① 在 概览 页确认发布状态是 测试中，不要点 发布应用； ② 在 目标对象 页的 测试用户 区域，只添加你自己的 Gmail，不要加别人。这样只有你能完成 Google 授权。

    6. 点左侧 品牌塑造，填写：
      • 应用名称：SafeCallRecorder
      • 用户支持邮箱：选你的 Gmail
      • 开发者联系信息：填你的 Gmail
      • 点 保存并继续
    7. 点左侧 数据访问：不用添加范围，直接点 保存并继续
    8. 回到 目标对象，找到 测试用户：
      • 点 添加用户（或 + 添加用户）
      • 输入你稍后用来「连接 Google 账号」的 Gmail
      • 点 添加 → 保存
    9. 点左侧 概览，确认 发布状态 为 测试中

    若左侧是旧版菜单：☰ → API 和服务 → OAuth 同意屏幕，按钮同样是「外部」「保存并继续」「添加用户」。

    步骤 3：启用 Google Drive API
    1. 点击：→ 打开 Google Drive API 页面
    2. 确认页面顶部当前项目名正确
    3. 看页面中间的大按钮：
      • 未启用：蓝色 启用 → 点它
      • 已启用：显示 管理 → 说明已完成，继续下一步

    手动路径：☰ → API 和服务 → 库 → 搜索 Google Drive API → 进入 → 点 启用

    步骤 4A：创建 OAuth 客户端（推荐 · Chrome 扩展程序）

    新版界面（左侧有「客户端」菜单）：

    1. 打开：→ 凭据 / 客户端页面
    2. 点左侧 客户端
    3. 点 创建客户端（或页面顶部 + 创建客户端）
    4. 应用类型 选 Chrome 扩展程序（或「Chrome 应用」）
    5. 名称 填 SafeCallRecorder
    6. 扩展 ID（或「项目 ID」）粘贴本页最上方显示的扩展 ID（整段复制，不要有空格）
    7. 点 创建
    8. 弹出小窗显示 客户端 ID（以 .apps.googleusercontent.com 结尾）→ 复制
    9. 粘贴到本页顶部 OAuth 客户端 ID 输入框，点击别处保存

    旧版界面：☰ → API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID → 同上填写。

    若「OAuth 客户端 ID」是灰色不可点，说明步骤 2 未完成，回去配置 目标对象 和 品牌塑造。

    步骤 4B：创建 OAuth 客户端（备选 · 没有 Chrome 扩展类型时）
    1. 左侧 客户端 → 创建客户端（或 ☰ → API 和服务 → 凭据 → 创建凭据）
    2. 应用类型 选 Web 应用
    3. 名称 填 SafeCallRecorder
    4. 已授权的重定向 URI → 点 添加 URI
    5. 粘贴本页最上方的 Web 应用重定向 URI（含 https:// 和末尾 /）
    6. 点 创建 → 复制 客户端 ID → 粘贴到本页顶部输入框
    步骤 5：回到本插件，连接 Google 并开始上传
    1. 确认本页顶部 OAuth 客户端 ID 已填写（粘贴后点击别处保存）
    2. 勾选 启用 Google Drive 上传
    3. 点 连接 Google 账号
    4. 在 Google 弹出窗口：选账号 → 继续 → 允许（若提示「Google 尚未验证此应用」，点 高级 → 前往 SafeCallRecorder（不安全），这是你自建的应用）
    5. 点 选择 Drive 文件夹 → 进入目标目录 → 选择当前文件夹；或点 使用默认文件夹
    6. 选上传方式；保持 停止录音后自动上传 MP3 勾选即可

    仍有问题？打开插件帮助页「Google 云端上传」。常见错误：重定向 URI 不匹配 → 检查 Web 应用 URI 是否完整；访问遭拒 → 在 目标对象 的 测试用户 里添加你的 Gmail，且发布状态保持 测试中。

SafeCallRecorder

录音默认保存在本机；启用 Google 云端上传后，MP3 可同步到 Google Drive。

第一次使用？按照 3 步开始录音

  1. 选择声音设备
  2. 确认音浪有变化
  3. 点击开始录音

最安全。停止后马上取得录音，MP3完成后再自动下载。

标准适合普通通话：短暂停顿不会立刻显示“没有声音”。

「标签页」：在浏览器中打开 mp3/mp4 并开始播放时自动录音。「插件内」：下方播放列表按顺序全部播完后再自动开始，播放过程中不会提前录音。

请确保所选设备能收到播放声音（例如 VoiceMeeter Out B1）。

隐私：录音只保存在本机浏览器存储中，不会上传。

可保存多套命名规则；开始录音与历史导出均使用当前选中的方案，文件名按该方案与录音开始日期生成。

    下载保存路径

    当前（浏览器「下载」）：浏览器下载文件夹 /

    若停止录音后弹出保存路径窗口，是浏览器下载设置所致（非插件问题）。请关闭「下载前询问每个文件的保存位置」：Brave 打开 brave://settings/downloads，Chrome 打开 chrome://settings/downloads。

    点绿色「使用下载文件夹」时，文件保存到浏览器「下载」目录；上方子目录名称会创建为「下载/子目录/」。这不是 Windows 的「图片」「文档」等系统文件夹。

    只有想保存到 D 盘等其他位置时，才需要点「选择其他位置…」并在其中新建子文件夹（例如 D:\录音）。

    从 Google Cloud 弹窗复制后，先粘贴到下方输入框（自动保存到本机）。建议同时备份到记事本/密码管理器，换电脑或重装扩展时要用。填写密钥并连接 Google 账号后，可一次授权、长期自动续期。

    Google Cloud 详细配置教程（点击展开 / 收起）

    首次使用？需要先用 Google 账号在 Google Cloud 免费创建 OAuth 客户端（约 5–10 分钟，只需配置一次）。以下按钮名称均按 Google 中文界面书写，请对照你屏幕上看到的文字点击。

    步骤 1：创建 Google Cloud 项目（没有项目就无法继续）

    推荐：直接打开新建项目页面（不用自己找按钮）

    1. 先登录 Google 账号，然后点击：→ 打开「新建项目」页面
    2. 在 项目名称 输入框填：SafeCallRecorder（或任意名称）
    3. 位置 保持默认「无组织」即可，不用改
    4. 点页面上的 创建 按钮（通常在输入框下方或右下角）
    5. 等待约 10–30 秒，浏览器右上角可能弹出「项目已创建」通知

    若你想手动找「新建项目」按钮，按这个路径：

    1. 打开 Google Cloud 控制台首页
    2. 看页面最顶上一行：左边是 ☰ 菜单，旁边是 Google Cloud
    3. Google Cloud 右边是 项目下拉框（可能显示项目名，或「选择项目」）→ 点它
    4. 弹出「选择项目」窗口 → 看窗口右上角的 新建项目 按钮（有时在窗口顶部「新建项目」标签页）→ 点它
    5. 填写项目名称 → 点 创建

    找不到「新建项目」？ ① 确认已用个人 Google 账号登录（公司账号可能被管理员禁止建项目）； ② 直接用上方「打开新建项目页面」链接； ③ 若列表里已有项目，也可不新建，在「选择项目」窗口里点选已有项目后继续步骤 2。

    创建后必做：再看一次页面顶部项目下拉框，确认显示的是你刚建的项目名（有时不会自动切换，需手动点选）。

    步骤 2：配置 OAuth 同意屏幕（左侧菜单「Google Auth Platform」）

    你会看到的左侧菜单（中文）：概览 · 品牌塑造 · 目标对象 · 客户端 · 数据访问 · 验证中心 · 设置

    新版界面：概览页没有「开始」按钮？ 这是正常的。Google 已更新界面，概览 页只会显示「尚未配置 OAuth 客户端」和右侧的 创建 OAuth 客户端。 先不要点「创建 OAuth 客户端」，请直接点左侧菜单按下面顺序配置；完成后再去步骤 4 创建客户端。

    1. 点击：→ 打开 OAuth 同意屏幕
    2. 确认页面顶部当前项目是你刚创建的项目（不对就先回步骤 1 切换）
    3. 若你在 概览 页：看到「尚未配置 OAuth 客户端」即可，无需找「开始」按钮，直接点左侧 目标对象
    4. 若左侧是旧版菜单且概览页有 开始 或 配置同意屏幕：点它进入向导，然后选 外部
    5. 在 目标对象 页：
      • 个人 Gmail：选 外部（内部 是灰色不可点 → 正常，需要公司 Workspace 账号）
      • 选好后点 创建 或 保存

    6. 只想自己用、不想给别人用？ ① 在 目标对象 页查看 发布状态（新版界面不在概览页显示），应为 测试中，不要点 发布应用； ② 在同一页的 测试用户 区域，只添加你自己的 Gmail，不要加别人。这样只有你能完成 Google 授权。

    7. 点左侧 品牌塑造，填写：
      • 应用名称：SafeCallRecorder
      • 用户支持邮箱：选你的 Gmail
      • 开发者联系信息：填你的 Gmail
      • 点 保存并继续
    8. 点左侧 数据访问：不用添加范围，直接点 保存并继续
    9. 回到 目标对象，找到 测试用户：
      • 点 添加用户（或 + 添加用户）
      • 输入你稍后用来「连接 Google 账号」的 Gmail
      • 点 添加 → 保存
    10. 仍在 目标对象 页，向上滚动查看 发布状态：
      • 应显示 测试中（或英文 In testing）→ 个人使用保持此状态即可
      • 概览 页通常不会显示发布状态，看不到是正常的
      • 若显示 正式版 / 已发布，且你只想自己用，一般无需改回；关键是测试用户里只有你自己

    若左侧是旧版菜单：☰ → API 和服务 → OAuth 同意屏幕，发布状态在同意屏幕页面顶部；按钮同样是「外部」「保存并继续」「添加用户」。

    步骤 3：启用 Google Drive API
    1. 点击：→ 打开 Google Drive API 页面
    2. 确认页面顶部当前项目名正确
    3. 看页面中间的大按钮：
      • 未启用：蓝色 启用 → 点它
      • 已启用：显示 管理 → 说明已完成，继续下一步

    手动路径：☰ → API 和服务 → 库 → 搜索 Google Drive API → 进入 → 点 启用

    步骤 4：创建 OAuth 客户端（推荐 · Web 应用）

    重要：在控制面板填写「OAuth 客户端 ID」时，必须创建 Web 应用 类型并配置重定向 URI。 若创建的是「Chrome 扩展程序」类型，连接时会报 redirect_uri_mismatch（错误 400）。

    ⚠ 创建前请准备记事本：点「创建」后弹窗会同时给出客户端 ID与客户端密钥，请立即复制保存（密钥只显示一次）。然后再粘贴到本插件输入框。

    1. 打开：→ 凭据 / 客户端页面
    2. 点左侧 客户端 → 创建客户端
    3. 应用类型 选 Web 应用（不要选 Chrome 扩展程序）
    4. 名称 填 SafeCallRecorder
    5. 已授权的重定向 URI → 点 添加 URI
    6. 必须添加本页最上方「Web 应用重定向 URI」显示的完整链接（每人不同，格式固定）：
      • 格式：https:// + 你的扩展 ID + .chromiumapp.org/
      • 示例（本地扩展）：https://emelhfpkanogoiegfanfbbgmglhiblfp.chromiumapp.org/
      • 以你控制面板实际显示为准（见本页顶部 —），整段复制，含 https:// 和末尾 /
      • 不要填 chrome-extension://…/dashboard.html 这种插件页面地址
    7. 点 创建 → 弹出窗口会同时显示：
      • 客户端 ID（以 .apps.googleusercontent.com 结尾）→ 粘贴到本插件 OAuth 客户端 ID
      • 客户端密钥（以 GOCSPX- 开头）→ 粘贴到本插件 OAuth 客户端密钥（见下一步）
    8. 回到本插件粘贴客户端 ID → 等待自动保存

    旧版界面：☰ → API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID → 应用类型选 Web 应用。

    步骤 4.5：获取 OAuth 客户端密钥（推荐 · 一次授权长期有效）

    为什么需要密钥？Google 规定：只有「客户端 ID + 客户端密钥」才能换取长期 refresh token。只填 ID 时登录约 1 小时过期，需频繁重连。

    1. 创建客户端时：步骤 4 点「创建」后的弹窗里，除客户端 ID 外还有 客户端密钥（格式 GOCSPX-xxxxxxxx）
      • 立即复制保存到记事本 — Google 只显示这一次，关闭弹窗后无法再查看完整密钥
      • 粘贴到本插件上方 OAuth 客户端密钥 输入框（密码框，粘贴后自动保存）
    2. 若当时没复制、弹窗已关闭：
      • 打开 → 凭据 / 客户端页面
      • 在 OAuth 2.0 客户端 ID 列表中，点你的客户端名称（如 SafeCallRecorder）进入详情
      • 看页面右侧或下方 客户端密钥 区域：
        • 若显示「密钥已隐藏」或只有末尾几位 → 点 添加密钥 或 + 添加密钥
        • 选 创建新密钥 → 弹出窗口显示新 GOCSPX-… → 立即复制
        • 旧密钥可保留或删除（删除后旧 refresh token 会失效）
      • 将密钥粘贴到本插件 OAuth 客户端密钥 输入框
    3. 保存密钥后，点 连接 Google 账号 重新授权一次（底部会提示「请重新点连接以启用长期自动续期」）
    4. 成功后界面显示：「Google 已长期授权，上传时会自动续期令牌」

    安全提示：客户端密钥相当于应用密码，请勿发到公开群或上传到 GitHub。导出云端配置会包含 ID、密钥与登录状态，换浏览器导入后通常无需再登录 Google；请仅保存在本机私密位置。

    步骤 4B（备选）：Chrome 扩展程序类型 — 不推荐用于控制面板

    此类型不能与「在控制面板粘贴客户端 ID」一起使用，否则会出现 redirect_uri_mismatch。仅适合高级用户直接修改 manifest.json 中的 oauth2.client_id。

    1. 左侧 客户端 → 创建客户端
    2. 应用类型 选 Chrome 扩展程序
    3. 扩展 ID 填本页最上方显示的 32 位扩展 ID（不是 Cloud 项目 ID）
    4. 点 创建 → 将客户端 ID 写入 manifest.json，而不是控制面板输入框
    步骤 5：回到本插件，连接 Google 并开始上传
    1. 确认 OAuth 客户端 ID 已保存；若需长期授权，确认 OAuth 客户端密钥 也已填写
    2. 勾选 启用 Google Drive 上传（保持勾选；「断开连接」不会取消此项）
    3. 点 连接 Google 账号
    4. 在 Google 弹出窗口：选账号 → 继续 → 允许（若提示「Google 尚未验证此应用」，点 高级 → 前往 SafeCallRecorder（不安全），这是你自建的应用）
    5. 点 选择 Drive 文件夹 → 进入目标目录 → 选择当前文件夹；或点 使用默认文件夹
    6. 选上传方式；保持 停止录音后自动上传 MP3 勾选即可

    仍有问题？打开插件帮助页「Google 云端上传」。常见错误：① redirect_uri_mismatch → 须用「Web 应用」客户端并添加本页显示的重定向 URI；② 粘贴客户端 ID 后变空 → 重新加载扩展后再粘贴；③ 概览页找不到「开始」→ 去目标对象配置；④ 访问遭拒 → 在测试用户添加你的 Gmail；⑤ 找不到客户端密钥 → 见步骤 4.5「添加密钥」；⑥ 显示已连接但无法上传 → 点「断开连接」后重新「连接 Google 账号」。
